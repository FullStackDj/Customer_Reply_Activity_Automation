Every Reply Becomes Clear Responsibility

Odoo already saves replies in chatter. The problem is that a message in a busy thread is easy to overlook. This module adds the missing operational step.

  1. Preserve the Conversation: Standard Odoo routing stores the external reply on the correct record.
  2. Find the Owner: The module reads the configured responsible field from that document.
  3. Create the Obligation: Odoo schedules “Customer replied — response required” with the configured deadline.
  4. Show the Context: The activity displays the sender, subject, received time, and reply count.
Result: the full email remains in chatter, while the required follow-up appears exactly where responsible users manage their work.

Configure Rules for the Models You Already Use

Stop installing separate reply notifiers for separate documents. Configure the models and ownership fields that already match your company.

  • Universal Model Rules: Opportunities, quotations, Sales Orders, invoices, Purchase Orders, pickings, project tasks, and custom models.
  • Your Existing Ownership: Select any Many2one or Many2many field linked to internal Odoo users.
  • Your Activity Type: Use the included Customer Reply type or another compatible activity type.
  • Your Response Deadline: Configure calendar days, weeks, or months for each document model.
Configure once per model. Keep one consistent customer-response policy across Sales, Purchasing, Finance, Operations, and Service.
